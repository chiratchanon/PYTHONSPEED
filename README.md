รายระเอียดเกี่ยวกับโปรเจกต์
    โปรเจกต์ “PYTHON SPEEDTYPE” คือแพลตฟอร์มการเรียนรู้และฝึกฝนทักษะการพิมพ์ ที่มุ่งเน้นการพิมพ์โค้ดภาษา Python โดยเฉพาะ โดยถูกพัฒนาขึ้นในรูปแบบของเว็บไซต์ ที่ผู้ใช้งานสามารถเข้าถึงได้ผ่านเว็บเบราว์เซอร์จากคอมพิวเตอร์เดสก์ท็อปหรือแล็ปท็อป
    โดยเป้าหมายหลักของโปรเจกต์นี้ คือการช่วยให้ นักศึกษา, และผู้ที่สนใจเรียนรู้ภาษา Python สามารถพัฒนาการพิมพ์ Keywords เฉพาะของภาษา Python ได้อย่างรวดเร็วและแม่นยำ เพื่อให้ผู้ใช้สามารถถ่ายทอดความคิดออกมาเป็นโค้ดได้ลื่นไหลยิ่งขึ้น และลดข้อผิดพลาด ที่มักเกิดขึ้นระหว่างการพัฒนาซอฟต์แวร์

ฝึกพิมพ์ภาษา Python ได้จริง: ผู้ใช้สามารถฝึกพิมพ์ Keyword ต่างๆ ของภาษา Python ที่ใช้บ่อย เช่น for, while, if-elif, print()

ใช้งานง่ายผ่าน Browser: ไม่ต้องติดตั้งโปรแกรมเพิ่มเติม เพียงเข้าผ่านเว็บไซต์ก็สามารถเริ่มฝึกได้ทันที

ระบบคะแนน : มีระบบ Score เพื่อให้ผู้ใช้สามารถติดตามฝีมือ

GAMEPLAY
Gameplay เป็นการพิมพ์ Keywords ของภาษา Python ที่ขึ้นมาให้ทันเวลาตามระดับความยากที่ผู้เล่นเลือก โดยจะมีสถานะต่างๆ ของ Keywords เพื่อเป็นตัวช่วยให้ผู้เล่นสามารรถทำคะแนนได้มากขึ้น และสามารถเล่นได้นานขึ้น โดย Keywords ที่โผล่ขึ้นมาจะมี 3 สถานะได้แก่

Keyword สีขาว : เป็น Keyword หลักที่จะโผล่ขึ้นมา เมื่อผู้เล่นพิมพ์ถูกต้อง จะเพิ่มคะแนนของผู้เล่นตามความยาวของ Keyword นั้น และจะลดพลังชีวิตของผู้เล่น หากเวลาหมด

Keyword สีเขียว : มีโอกาสโผล่ขึ้นมา 1/10 ตลอดการเล่น เมื่อผู้เล่นพิมพ์ถูกต้อง จะเป็นการเพิ่มพลังชีวิตของผู้เล่น 1 ครั้ง หากพลังชีวิตของผู้เล่นเท่ากับหรือมากกว่า 3 จะไม่เพิ่มพลังชีวิตผู้เล่นอีก จะลดพลังชีวิตของผู้เล่น หากเวลาหมด

Keyword สีแดง : มีโอกาสโผล่ขึ้นมา 1/10 ตลอดการเล่น เป็น Keywords ที่ยากในการพิมพ์ เมื่อผู้เล่นพิมพ์ถูกต้อง จะเพิ่มคะแนนของผู้เล่นเป็น 2 เท่าตามความยาวของ Keyword และเพิ่มพลังชีวิตของผู้เล่น 1 ครั้ง หากพลังชีวิตของผู้เล่นเท่ากับหรือมากกว่า 3 จะไม่เพิ่มพลังชีวิตผู้เล่นอีก จะลดพลังชีวิตของผู้เล่น หากเวลาหมด
